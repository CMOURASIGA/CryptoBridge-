# Roadmap
1. CP-01: TypeScript foundation, exchange adapter interface, stdio MCP, tests and CI (this candidate).
2. CP-02: audited Mercado Bitcoin authenticated read access, after a secure credential store is available.
3. CP-03: portfolio history, accurate analytics and visual UI, with no fabricated history.
4. CP-04: scheduler + notifications + idempotency; design for individual user consent.
5. CP-05: remotely hosted authenticated MCP for ChatGPT, verified end-to-end.
6. CP-06: multi-tenant isolation, penetration and regression tests; enforce trade blockade.
7. CP-07: public distribution review for platform and exchange contractual compliance.

Blockers: private-account credential store, end-user authorization, HTTPS MCP service, real-account read-only homologation, notification infrastructure.
