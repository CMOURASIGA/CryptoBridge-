# AN-02 | CoinGecko reference feed and deterministic analysis

Scope: BRL CoinGecko aggregated reference feed for BTC, ETH, SOL (90-day request, daily UTC sample), separately from the Mercado Bitcoin exchange ticker. This is NOT an exchange execution quote, NOT provider MB historical candles, and NOT a fallback labeled Mercado Bitcoin.
MCP tools:
- get_reference_price: pair; source timestamp, fetchedAt, freshness gate 10 min.
- analyze_market_reference: pair, days 60-90; daily sampled prices, SMA20/SMA50, RSI14, annualized volatility20, change/drawdown20 and heuristic regime; flags ATR unavailable (no OHLC), volume not evaluated, trading disabled.

Regime heuristics, subject to future empirical validation: crash if 20-day drawdown <= -15%; otherwise agitated if annualized 20-day volatility >= 90%; otherwise lateral if abs(20-day change)<3%; otherwise trending calm. These are descriptive heuristics, NOT indicators of trading eligibility or reliable future returns.
Require 51+ complete consecutive UTC dates, last source price within 48 hours, no future timestamps. Reject malformed/non-JSON/stale responses, rate limits or insufficient data; do not substitute zeros or hallucinate figures.
CoinGecko public API may impose quota or require a Demo API key in some situations. Optional env COINGECKO_DEMO_API_KEY stored only as Vercel secret if required; never paste in chat or repo. Rate limits and terms must be reviewed before external/commercial distribution.
No private-account access or trading enabled. No automatic asset purchases. HV-03 remains specific to Mercado Bitcoin and can only PASS with valid MB market quotes.

Sources: https://docs.coingecko.com/reference/simple-price and https://docs.coingecko.com/reference/coins-id-market-chart .
